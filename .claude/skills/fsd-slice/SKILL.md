# Создание FSD-слайса (Vue 3 + Nuxt 4)

Правила проекта: `docs/fsd.md`. Прочитай его, если не в контексте.

## Шаги

1. **Определи слой.** Задай себе вопросы:
   - Это бизнес-сущность с данными (курс, преподаватель, отзыв)? → `entities`
   - Это действие пользователя с бизнес-ценностью (отправить заявку)? → `features`
   - Это крупный самодостаточный блок страницы (hero, каталог, слайдер)? → `widgets`
   - Это композиция целой страницы? → `pages` (используй skill `fsd-page`)
   - Это UI без бизнес-смысла (кнопка, аккордеон, карусель)? → это НЕ слайс, клади в `shared/ui`
   Если сомневаешься между двумя слоями — выбирай нижний (ближе к shared): поднять слайс выше потом дешевле, чем опустить.

2. **Имя слайса** — kebab-case, по бизнес-смыслу, без суффиксов слоя (`course-catalog`, не `course-catalog-widget`).

3. **Создай структуру.** Только нужные сегменты, ничего «про запас»:
   ```
   src/<layer>/<slice-name>/
     index.ts          # публичный API — только то, что нужно снаружи
     ui/<name>.vue     # SFC: <script setup lang="ts"> → <template> → <style lang="scss" scoped>
     model/            # типы, данные, состояние — только если есть
     lib/              # хелперы слайса — только если есть
   ```

4. **Публичный API.** В `index.ts` экспортируй минимум. Всё, что не экспортировано — приватное. Компоненты экспортируй PascalCase-именем: `export { default as CourseCard } from './ui/course-card.vue';`

5. **Проверь импорты.** Только нижние слои и только через их публичный API. Кросс-импорт внутри слоя запрещён (для entities — только через `@x`). Auto-imports в проекте отключены: Nuxt-composables — явно из `#imports`, `NuxtLink` и пр. — из `#components`.

6. **Стили:** `<style lang="scss" scoped>`, синтаксис `@use`/`@forward` (не `@import`). Цвета — только `var(--токен)` из `src/app/styles/_colors.scss`, сырые hex запрещены; новые цвета в палитру не добавлять без согласования с дизайнером. Токены типографики/брейкпоинтов пока не заведены. Анимации: CSS-first (см. `docs/architecture.md`, раздел «Анимации»), уважать `prefers-reduced-motion`.

7. **Проверь:** `npm run lint` (boundaries), `npm run lint:fsd` (Steiger), `npm run typecheck`. Нарушения границ чинить переносом кода, а не отключением правила.

## Анти-паттерны

- Компонент в `shared/ui` со знанием о курсах/преподавателях — перенести в entity.
- Виджет, импортирующий другой виджет — вынести общее в feature/entity/shared.
- «Пустой» слайс из одного файла-обёртки — возможно, это просто компонент внутри существующего слайса.
- Полагаться на auto-import (он отключён) — все импорты явные.
