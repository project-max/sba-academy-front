# Секция лендинга по макету

Конвейер «дизайн → код». Перед началом: `docs/pages.md` (какие секции у страницы), `docs/fsd.md` (маппинг «блок → слайс»), `docs/architecture.md` (таблица анимаций).

## Шаги

1. **Найди секцию** в `docs/pages.md` и в таблице маппинга `docs/fsd.md`. Нет в таблицах — сначала добавь.

2. **Определи форму:** новый widget / расширение существующего / примитив в `shared/ui` — по критериям skill `fsd-slice`. Один крупный блок страницы = один widget. Корень секции — глобальный класс `.container` (max 1440 + поля 64, контентная область 1312 — см. `_layout.scss`), внутренняя карточка/контент — `width: 100%`. Фон во всю ширину экрана — редкое исключение: корень без `.container`, класс на внутренней обёртке. Медиазапросы пока не писать (брейкпоинты появятся на этапе адаптива).

3. **Контент СНАЧАЛА в данные** (skill `add-content`): тексты/цифры секции — в data-файл entity, потом UI. Хардкод текста в шаблоне запрещён.

4. **Анимации — строго по таблице** `docs/architecture.md` → «Анимации и интерактив»:
   - hover, якоря — чистый CSS;
   - аккордеон — нативный `<details name>`/`<summary>`;
   - слайдер — `embla-carousel-vue` (обёртка в `shared/ui/carousel`, когда появится);
   - scroll-reveal / стаггер — motion-v: `whileInView` + `viewport: { once: true }`;
   - простые enter/leave — `<Transition>` Vue.
   Обязательно: `prefers-reduced-motion` уважается, анимируем только `transform`/`opacity`, reveal однократный.

5. **Семантика и a11y:** `<section>` с `aria-label` или заголовком `h2`/`h3` (иерархию не ломать), якорные `id` — как в `docs/pages.md`; изображения с осмысленным `alt`; интерактив доступен с клавиатуры.

6. **Изображения:** в `public/images/…`, через принятый пайплайн (см. чек-лист «дизайн утверждён» в architecture.md); обязательные width/height против CLS; lazy ниже первого экрана.

7. **Финал:** `npm run check`.

## Анти-паттерны

- Хардкод текста/цифр в шаблоне.
- Widget импортирует widget — выноси общее вниз (feature/entity/shared).
- JS-анимация там, где хватает CSS.
- Стили «на глаз» вместо токенов (после их появления).
