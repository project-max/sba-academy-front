# Проверка перед релизом

## Блокеры (релиз невозможен)

1. **Заглушка форм.** `grep` по `src/shared/api` на `[stub]`/`TODO`: пока `submitApplication` — заглушка, релиз страницы с формой ЗАПРЕЩЁН — молча теряются заявки (главная конверсия сайта). Эндпоинт должен быть подключён и проверен руками.
2. **`npm run check` зелёный** (lint + steiger + typecheck + generate с failOnError).

## Чек-лист

3. В `.output/public` присутствуют все роуты из `docs/pages.md` (9 каталогов с index.html) + `404.html`.
4. Якоря согласованы: `Course.anchor` ↔ ссылки в navigation.ts ↔ `id` секций на `/programs`.
5. У каждого индексируемого роута — title («… — SBA Academy») и description; `/privacy`, `/oferta`, error-страница — noindex.
6. Внешние ссылки живы: `cabinet.academysba.pro`; судьба `/rating.php` решена (редирект/отказ — см. docs/pages.md).
7. Все `<img>` с alt; нет битых путей на изображения/видео.
8. `robots.txt` и `sitemap.xml` присутствуют в статике (когда будут заведены — до того отметить осознанно).
9. Контент сверен с финальной редакцией заказчика (черновые тексты из courses.data.ts — сверить обязательно).
10. Тестовые/превью-домены закрыты от индексации (Disallow: /).

## После деплоя

- Проверить руками: главная, /programs, отправка формы, 404 на несуществующем URL.
- Первые недели мониторить 404 в access.log — пополнять карту 301-редиректов со старого сайта.
